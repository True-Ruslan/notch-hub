# NotchHub v0.2.0 — Personal build

## Personal build — not notarized

This release is for personal use. It is ad-hoc signed with App Sandbox and Hardened Runtime enabled, but it is not Developer ID signed or Apple-notarized. macOS may require Finder **Open** or **System Settings → Privacy & Security → Open Anyway** on first launch. Do not disable Gatekeeper.

## What is new since v0.1.0

`v0.1.0` published the engineering foundation only. Everything below was implemented, automated-tested, physically accepted (or explicitly waived by the product owner, noted below) and merged since then, and is included in this version for the first time:

- **Multi-monitor support (M1)** — event-driven active-display migration: Compact, Peek and Expanded correctly follow display connect/disconnect/reconfigure, preserving hardware-notch-first screen selection with a safe fallback when no hardware notch is present.
- **Universal Media (M6.1–M6.10)** — a system-wide Now Playing media experience built around the notch:
  - live media artwork, title, artist and transport controls in Peek and Expanded;
  - gestures: horizontal swipe for next/previous, draggable seek, Hover Peek with tuned dwell/exit timing;
  - Compact reflects live playback state at all times, including a small animated equalizer while playing;
  - a real-time ticking progress timeline in Peek/Expanded while playing;
  - marquee scrolling for overflowing titles/artists/albums, disabled automatically when Reduce Motion is on;
  - a discoverable way to quit the app — a menu-bar status item with a "Quit NotchHub" action — fixing a defect where Force Quit was the only option and skipped cleanup, leaving an orphaned helper process behind.
- **Two real runtime defects found and fixed by hardware testing**, not visible in CI alone: an expanded-size panel that could get stuck showing compact content after a display/compositor change, and a persistent global pointer-motion observer that amplified unrelated external-monitor activity into extra system wakeups. Both are corrected; global pointer observation is now bounded to an actual in-progress interaction instead of running continuously.
- **Whole-app performance/resource review (P1)** — CPU, memory, thread and idle-wakeup behavior measured end-to-end on the target Mac and accepted against explicit thresholds; no speculative optimization was needed.

## Security posture

This personal build remains deliberately constrained:

- App Sandbox enabled;
- Hardened Runtime enabled;
- no telemetry, analytics, advertising, licensing backend, or remote-control channel;
- no direct runtime network/WebKit API;
- no runtime shell/subprocess execution beyond the existing reviewed, fixed-path system media adapter;
- no dynamic code or plug-in loading;
- no global keyboard, button, drag, scroll, or modifier monitoring;
- global pointer (`mouseMoved`) observation is bounded to an actual in-progress NotchHub interaction rather than persistently armed in idle;
- no bundled credentials, API keys, certificates, or private keys.

The release is ad-hoc signed. The signature protects bundle integrity after build, but it does **not** establish an Apple-verified developer identity and the release is **not notarized**.

## Installation and first launch

1. Download `NotchHub.dmg` from this GitHub Release.
2. Verify it against the accompanying `NotchHub.dmg.sha256` checksum if desired.
3. Open the DMG and place `NotchHub.app` in Applications.
4. Open the application using Finder **Open**.
5. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway** and confirm the launch through the standard macOS prompt.

Do not disable Gatekeeper or weaken macOS security settings globally.

## Provenance

The release publishes these assets together:

- `NotchHub.dmg` — application installer;
- `NotchHub.dmg.sha256` — SHA-256 checksum;
- `build-metadata.json` — source commit, build number, runner/toolchain versions, artifact sizes, checksum, and explicit distribution-trust flags.

A published version/tag is immutable. If a defect is found, it will be fixed in a new version rather than silently replacing this release artifact.

## Known limitations

- Shelf, Snippets, Calendar, Translator, and a Settings module are not implemented yet.
- Physical acceptance for the marquee-text feature was explicitly waived by the product owner rather than performed on real hardware before merge; see `docs/testing/M6_9_MEDIA_MARQUEE_ACCEPTANCE.md` for the recorded residual risk.
- Remaining fullscreen/Spaces/notchless hardening beyond the accepted M1 scope is deferred to a future slice.
- Because this build is not Developer ID signed/notarized, macOS trust warnings on first launch are expected for a downloaded copy.
- Trusted Developer ID/notarized distribution remains an optional future tier if Apple Developer Program membership becomes worthwhile.
